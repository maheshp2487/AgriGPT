1.1 Origin & Purpose
`C:\Users\mahesh\Desktop\agrigpt` represents the client-side demonstration prototype of AgriGPT ("AgriGPT Demo" / `agrigpt-demo`), developed as an interactive showcase for Samunnati Finance and academic collaboration with VIT Vellore. 

1.2 Key Differences from the Production Repo (`d:\Projects\AgriGPT`)
While `d:\Projects\AgriGPT` (detailed in `mainagri.txt`) is a multi-tier production system comprising Next.js 16 App Router, Python FastAPI, PostgreSQL/pgvector, live government OGD AGMARKNET APIs, and DPDP Act 2023 compliance, this desktop repo (`subagri.txt`) is an ultra-fast, zero-backend-dependency React + Vite client designed for:
1. Immediate demonstration on low-spec hardware without starting a Python or PostgreSQL daemon.
2. Direct deployment to GitHub Pages (`gh-pages`) via GitHub Actions.
3. Rapid toggling between built-in simulated intelligence, Indian National Language Translation Mission (NLTM Bhashini ULCA API), Groq LLaMA 3.3 70B, and Google Gemini 1.5 Flash.
4. Rich visual empathy featuring an animated SVG villager avatar with synchronous mouth movement, voice activity glow rings, and direct regional speech synthesis.

5. PLUGGABLE AI ENGINE ARCHITECTURE
================================================================================
Managed in `src/services/aiService.js`, the platform operates under a flexible 4-provider model configured via `AI_CONFIG`.

5.1 Built-in Regex & Agronomic Reasoning Engine (`generateDynamicAgriResponse`)
- Zero API key requirement — runs 100% offline in browser memory.
- Uses multi-lingual regex matching to classify farmer queries into 5 agronomic intents:
  1. `isPest`: Symptoms, blast, bollworm, curl, caterpillars, chemical and bio-sprays.
  2. `isPrice`: Mandi rates, modal price, quintal values, APMC trends for tomato, paddy, onion.
  3. `isSow`: Sowing windows, high-yield varieties, certified seed rates, crop calendar.
  4. `isScheme`: PM-KISAN, crop insurance, KCC loans, farm subsidies.
  5. `isSoil`: Soil types (red loam, clay), irrigation, DAP, Urea, Potash, biofertilizers.
- Generates comprehensive, localized markdown answers with exact chemical names (Tricyclazole, Chlorantraniliprole, Emamectin Benzoate), bio-controls (Pseudomonas fluorescens, Neem oil 10,000 ppm, Trichoderma viride), and per-acre dosages.
- Returns both formatted text and an `audioText` string stripped of markdown for text-to-speech synthesis.

5.2 Bhashini ULCA Translation Pipeline (`callBhashiniPipeline`)
- Connects to India's National Language Translation Mission (NLTM):
  `https://dhruva-api.bhashini.gov.in/services/inference/pipeline`
- Headers: `userID: AI_CONFIG.bhashiniUserId`, `ulcaApiKey: AI_CONFIG.bhashiniApiKey`.
- Enables high-accuracy government-grade machine translation between English agronomic corpuses and Indian regional languages.

5.3 Groq Cloud LLaMA 3.3 70B Integration (`callExternalLLM`)
- Endpoint: `https://api.groq.com/openai/v1/chat/completions`.
- Model: `llama-3.3-70b-versatile`.
- Temperature: `0.3`, Max Tokens: `850`.
- System Instruction: Forces the model to act as an ICAR-grounded agricultural scientist and answer strictly in the target regional language using farmer-friendly terminology.

5.4 Google Gemini 1.5 Flash Integration
- Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=...`.
- Lightweight, fast model for streaming natural vernacular responses.

5.5 LocalStorage AI Configuration System (`AiConfigModal.jsx`)
- Keys preserved across browser reloads:
  * `agrigpt_provider`: `'built-in'` | `'bhashini'` | `'gemini'` | `'groq'`
  * `agrigpt_bhashini_userid`
  * `agrigpt_bhashini_apikey`
  * `agrigpt_bhashini_pipelineid`
  * `agrigpt_gemini_key`
  * `agrigpt_groq_key`

6. AUDIO & VOICE SUBSYSTEM
================================================================================
6.1 Web Speech API Speech-to-Text (STT)
- Implemented in `ChatAssistant.jsx` (`handleToggleVoice`).
- Uses `window.SpeechRecognition` or `window.webkitSpeechRecognition`.
- Dynamically assigns `recognition.lang` matching active language BCP-47 tag (e.g. `ta-IN`, `hi-IN`).
- Automatically commits recognized text and triggers `handleSendQuery`.

6.2 Vite Development Server TTS Proxy Plugin (`ttsProxyPlugin`)
- Custom middleware defined directly inside `vite.config.js`:
  ```javascript
  server.middlewares.use('/api/tts', async (req, res) => {
    const url = new URL(req.url, 'http://localhost:5173');
    const q = url.searchParams.get('q') || '';
    const tl = url.searchParams.get('tl') || 'ta';
    const targetUrl = `https://translate.google.com/translate_tts?ie=UTF-8&q=${encodeURIComponent(q)}&tl=${tl}&client=tw-ob`;
    const response = await fetch(targetUrl, {
      headers: { 'User-Agent': 'Mozilla/5.0...' }
    });
    res.setHeader('Content-Type', 'audio/mpeg');
    const arrayBuffer = await response.arrayBuffer();
    res.end(Buffer.from(arrayBuffer));
  });
  ```
- Solves CORS restrictions and provides high-quality MP3 audio synthesis for regional languages.

6.3 Client SpeechSynthesis Read-Aloud Fallback (`playAgriAudio`)
- When running in production or GitHub Pages without local Vite server middleware, gracefully falls back to browser native `window.speechSynthesis`.
- Automatically selects native regional voices matching language code.
- Calibrated to rate `0.92` and pitch `1.0` for rural listening cadence.

7. INTERACTIVE VISUAL & FARMER-FIRST COMPONENTS
================================================================================
7.1 Animated SVG Farmer Avatar (`FarmerAvatar.jsx`)
- Renders an authentic Indian villager/farmer (with turban/gamcha) or agricultural scientist.
- Synchronous Facial Animation:
  * Blinking loop: Timer triggers eyelid closure every 4 seconds for 200ms.
  * Mouth movement: During active audio playback (`isSpeaking`), mouth toggles open/closed every 180ms to simulate talking.
  * Voice Activity Ring: Pulsing emerald/amber glow ring when speaking, pinging red ring when listening to microphone input.

7.2 Architecture & Blueprint Modal (`ArchitectureModal.jsx`)
- 3 interactive tabs detailing the platform's vision:
  1. Layer 1: Multilingual Farmer Experience (Voice In via Whisper/Bhashini, Voice Out, Farmer UI).
  2. Layer 2: Gateway & Spatial Context Engine (FastAPI/Node engine, APMC geolocation, soil zones).
  3. Layer 3: AgriGPT Agent & Vector Knowledge (FAISS vector DB, ICAR Krishi manuals, Agmarknet Redis cache).
- Tab 2 highlights official data grounding:
  * Agmarknet Portal (`http://agmarknet.gov.in/`): 3,000+ APMC mandis.
  * ICAR Krishi Repository (`http://krishi.icar.gov.in/`): Package of Practices.
  * Bhashini AI4Bharat (`https://bhashini.gov.in/`).
- Tab 3 articulates the Samunnati Finance value proposition: aggregation, market linkage, working capital credit linkage.

7.3 Crop Planner (`CropPlanner.jsx`)
- Focused on the October-November (Rabi / Samba) season.
- Displays responsive 4-column cards for key crops:
  1. Samba Paddy (ADT-53, CR-1009)
  2. Groundnut (TMV-13, Kadiri-6)
  3. Maize (Co-6 Hybrid)
  4. Hybrid Cotton
- Cards display: Expected profit/acre (e.g. ₹50,000 to ₹85,000), harvest time (105–135 days), suitable soil, profit star rating, and direct "Ask About This Crop" CTA.

7.4 Mandi Rates & Gauge Meter (`MandiRates.jsx`)
- Covers Tamil Nadu APMC hubs: Vellore Market, Ambur Market, Tiruvannamalai, Koyambedu.
- Features dynamic visual gauge meter calculating modal price position within min-max trading range:
  $$\text{Gauge } \% = \frac{\text{Modal Price} - \text{Min Price}}{\text{Max Price} - \text{Min Price}} \times 100$$
- Visual trend arrows (Green up / Red down) and actionable selling tips (e.g. "Hold stock for 3 days; supply dropping").

7.5 Schemes Guide (`SchemesGuide.jsx`)
- Highlights direct welfare schemes:
  1. PM-KISAN: ₹6,000/year via direct DBT.
  2. PMFBY Crop Insurance: 1.5% to 2% premium, 72h loss claim intimation.
  3. Kisan Credit Card (KCC): 4% subsidized interest rate, up to ₹3 Lakh collateral-free loan.
- Clear 1-tap "How to Apply" action button triggering assistant explanation.
